🔐 포트폴리오 관리자

폼을 채우고 저장하면 GitHub의 apps.json이 바로 업데이트돼요. 저장 후 1~2분 뒤 강력 새로고침(Ctrl+Shift+R)으로 확인하세요.

⚙️ 저장소 설정 (처음 한 번만 확인하면 됩니다)

토큰이 없다면 GitHub → 우측 상단 프로필 → Settings → Developer settings → Personal access tokens → Fine-grained tokens에서 발급하세요. Repository access는 해당 저장소만 선택하고, Permissions에서 Contents: Read and write로 설정하면 됩니다. 이 admin.html 링크와 토큰은 다른 사람과 공유하지 마세요.
